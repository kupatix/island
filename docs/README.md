# Сайт Островка

Готовый сайт для GitHub Pages: `index.html`, снимки в папке `img`, значки и `og.jpg`
(картинка, которую Telegram и VK показывают под ссылкой). Ничего собирать не нужно.

Адрес после включения: **https://kupatix.github.io/island/**

## Как включить GitHub Pages

1. Возьми папку `docs` (она уже лежит в архиве `Ostrovok-site.zip`, просто распакуй его).
   Если работаешь с папкой `site_release`, сделай её копию и назови копию `docs`.
2. Открой https://github.com/kupatix/island → кнопка **Add file** → **Upload files**.
3. Перетащи папку `docs` целиком в окно. Внизу нажми зелёную кнопку **Commit changes**.
4. Вверху репозитория открой **Settings**, слева выбери **Pages**.
5. В **Source** выбери **Deploy from a branch**. В **Branch** выбери `main` и папку `/docs`, нажми **Save**.
6. Подожди пару минут и обнови страницу: сверху появится ссылка на сайт.

Если сайт уже включён и ты обновляешь его: загрузи новую папку `docs` так же (Add file → Upload files),
GitHub заменит старые файлы.

## Релиз

- Главная кнопка «Скачать» ведёт на `releases/latest/download/OstrovokSetup.exe`, запасная ссылка —
  на `Ostrovok.zip`. Чтобы они заработали, в **Releases** нужен выпуск с тремя файлами:
  `OstrovokSetup.exe`, `Ostrovok.zip` и `version.json` (последний нужен для автообновления).
- До 00:00 ночи на 27 ноября (по Москве) сайт показывает обратный отсчёт «Релиз сегодня в 00:00»,
  а кнопки «Скачать» вместо пустой страницы GitHub пишут, сколько осталось. Как только выпуск
  появится на GitHub, кнопки сразу начнут скачивать. Время меняется в строчке `const RELEASE_AT` в `index.html`.
- VirusTotal: проверь файлы на virustotal.com, открой `index.html` и найди строчку
  `const VIRUSTOTAL_URL = "";`. Вставь ссылку на отчёт между кавычками.
- Трейлер: вставь ссылку на YouTube в строчку `const TRAILER_URL = "";`. Блок с видео появится сам.
- Номер версии на сайте — **1.0**, он записан прямо в `index.html` (найди «1.0», если захочешь поменять).
  Выпуск на GitHub лучше назвать тегом `v1.0`.
- Размеры файлов сайт берёт из GitHub сам. Если GitHub не ответит, покажет «482 КБ» и «7,1 МБ».

## Как поменять сайт потом

Открой `docs/index.html` на GitHub, нажми на карандаш, поправь текст и нажми **Commit changes**.
Через минуту-две сайт обновится.
